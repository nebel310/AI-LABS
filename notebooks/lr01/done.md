### ЛР1
**Цель:** Изучить основы языка Python.
**Что делал:** Объявлял переменные базовых типов (`int`, `float`, `str`, `bool`, `list`, `tuple`, `set`, `dict`). Реализовал набор функций: арифметика (разность, калькулятор), условная логика, подсчёт уникальных элементов, счётчик вхождений, парсинг и перемножение чисел из строки, тригонометрическая функция `sin(x)·cos(x)`, произведение по формуле с `math`. Решил 7 задач: перевод минут в часы/минуты, минимум из трёх без `min`, удаление символа через `.replace()`, удаление каждого 3-го символа, максимум и его индекс, вставка в конец через `append`, количество уникальных через `set`. Написал классы `Vehicle`, `Truck` (наследник) и `MyList` с методами суммы (без `sum`), реверса и слайсинга.
**Что получил:** Отточил навыки написания Python-кода руками, познакомился с синтаксисом классов и наследования, научился читать `assert`-проверки как тесты корректности.
